# Бей посуду

Антистресс-игра: пишешь мысль на посуде и разбиваешь её о стену.

## Запуск

```bash
npm install
npm run dev      # локально с автообновлением
npm run build    # готовая сборка в папке dist/
npm run preview  # посмотреть сборку
```

Папку `dist/` можно выложить на любой статический хостинг (Netlify, Vercel, GitHub Pages).

## Где что менять

| Что | Файл |
| --- | --- |
| Записки и как часто они выпадают | `src/config/notes.js` |
| Фразы после удара, комбо, котики | `src/config/locations.js` |
| Виды посуды (размер, цвет текста, осколки) | `src/config/dishes.js` |
| Как выглядит посуда | `src/dishes/paint.js` |
| Звуки посуды | `src/config/sounds.js` |
| Локации | `src/scenes/*.js` |
| Фото салона | `src/assets/showroom.jpg` |
| Котики | `src/cats.js` |

## Структура

```
src/
  main.js          игровой цикл, бросок, ввод
  state.js         общее состояние (размеры экрана, осколки, котики)
  ui.js            тосты, комбо, записки
  audio.js         все звуки (Web Audio, без файлов)
  shards.js        физика и отрисовка осколков
  effects.js       пыль, трещины, сердечки
  cats.js          два белых котика
  storage.js       localStorage с защитой от ошибок
  config/          тексты и настройки
  dishes/          отрисовка посуды и разрезание на осколки
  scenes/          кухня, салон Maserati, крыша
  lib/             математика и рисование
```
